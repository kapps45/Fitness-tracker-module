# 🏃 Fitness Tracker Module

Backend-модуль на Go для обработки данных о физической активности. Проект рассчитывает показатели активности пользователя на основе количества шагов, продолжительности, типа активности и параметров пользователя.

## Возможности

- расчёт количества шагов;
- расчёт пройденной дистанции;
- расчёт средней скорости;
- расчёт расхода калорий;
- поддержка ходьбы и бега;
- использование роста и веса пользователя при расчёте расхода энергии.
