# 🏃 Fitness Tracker Module

Backend-модуль на **Go** для обработки данных о физической активности пользователя.

Приложение получает информацию о тренировках и прогулках, рассчитывает основные показатели активности и формирует итоговую информацию о выполненных упражнениях.

## 🔧 Возможности

- 🏋️ Обработка данных о тренировках и прогулках
- 📏 Расчёт пройденной дистанции
- ⚡ Определение средней скорости
- 🔥 Расчёт расхода энергии
- 👤 Работа с данными пользователя
- 🏃 Поддержка разных типов физической активности
- 📊 Вывод общей информации об активности

## 📦 Структура проекта

| Компонент | Назначение |
|---|---|
| `spentenergy` | Расчёт дистанции, скорости и расхода энергии |
| `personaldata` | Хранение параметров пользователя |
| `trainings` | Обработка данных о тренировках |
| `daysteps` | Работа с данными о прогулках и шагах |
| `actioninfo` | Общий интерфейс для вывода информации об активности |

Основные исходные файлы находятся в каталоге `internal`, а запуск приложения выполняется через `cmd/tracker`.

## 🛠️ Используемые технологии

- **Go**
- `time`
- `strconv`
- `strings`
- `log`
- Стандартная библиотека Go

## 🚀 Запуск

Для запуска приложения выполните:

    go run ./cmd/tracker

## 🧪 Тестирование

Для проверки отдельных компонентов проекта предусмотрены автоматизированные тесты.

Запуск всех тестов:

    go test ./...

Проверка покрытия:

    go test -cover ./...
